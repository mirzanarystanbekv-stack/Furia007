# МаршрутПоступления — персональный маршрут поступления

Веб-сервис для абитуриентов: от анкеты до персональных рекомендаций вузов, сравнения и пошагового плана действий. Проект на хакатон **LOCUS 2026, кейс №2 «Персональный маршрут поступления»**.

## Стек

- **React 18** + **Vite 5** — SPA без серверной части
- **Tailwind CSS 3** — единая дизайн-система (палитра, кнопки, карточки)
- **react-router-dom 6** — маршрутизация между шагами сценария
- **localStorage** — хранение профиля, прогресса и аккаунтов; локальная демо-авторизация (SHA-256 через Web Crypto, работает офлайн)

> Отклонение от ТЗ (§7): JS вместо TypeScript, Context вместо Zustand/RHF, скоринг rule-based без LLM-роута — выбор в пользу скорости и надёжности на хакатоне; вся логика воспроизводима и детерминирована.

## Архитектура

```
src/
  data/
    universities.json   # 40 программ, 11 стран, 7 направлений; verified-поля со ссылками,
                        # demo-поля с бейджами «демонстрационные данные»
    fearModes.js        # конфигурация режимов «главного страха» (банер, сортировка)
    options.js          # опции анкеты + демо-профиль Алихана
  engine/
    scoring.js          # rule-based скоринг: +30 направление, +25 страна, +20 язык,
                        # +15 бюджет, +10 дедлайн, +5 достижения; грант-множитель;
                        # каждая причина хранится как {reason, points}
    roadmap.js          # генератор шагов с датами: экзамены, заявки, Hazırlık, документы
  context/
    ProfileContext.jsx  # профиль, избранное, прогресс — автосохранение в localStorage
  components/           # Layout, бейджи verified/demo, кольцо прогресса
  pages/                # 7 экранов пользовательского сценария
```

## Пользовательский сценарий (7 шагов)

1. **Landing** `/` — ценность сервиса, градиентный фон с линией маршрута, призыв к действию; опциональная регистрация/вход (`#/auth`), сессия в localStorage
2. **Профиль** `/profile` — анкета из 8 полей (класс, направления — до 3 интересов, страны, GPA+достижения, IELTS+уровень языка, бюджет, приоритет, главный страх)
3. **Диагностика** `/diagnostics` — сильные стороны, риски, цель, бейдж «демонстрационная оценка» у модельного вывода о GPA>4.5
4. **Рекомендации** `/recommendations` — каталог всех подходящих программ: поиск по вузу/программе/городу, фильтры по направлению и стране, слайдер стоимости, сортировка (совпадение/дешевле/ближе дедлайн), избранное ★, выбор двух программ для сравнения, сетка в 2 колонки на ноутбуке
5. **Сравнение** `/compare` — сравнение любых программ из рекомендаций (селекты колонок): стоимость, дедлайн, язык, трек, город
6. **Roadmap** `/roadmap` — таймлайн с датами: экзамены (TR-YÖS, IELTS, ЕНТ), окна подачи, Hazırlık при языковом разрыве, документы; печать плана
7. **Следующее действие** `/next` — один ближайший шаг с чекбоксом и кольцом прогресса

## Персонализация (реактивность)

Рекомендации, диагностика и roadmap — производные значения, пересчитываются мгновенно при любом изменении анкеты: смените бюджет/страны/GPA — список программ и план меняются сразу.

## Источники и флаги данных

- `verified: true` — поля подтверждены официальной страницей вуза (ссылка в записи, иконка-бейдж в UI: METU, ITU, Sakarya).
- `verified: false` — оценочные данные: в UI помечены бейджем «демонстрационные данные», перед подачей перепроверяются на сайте вуза.
- Вывод «GPA > 4.5 → топ-гранты» — модельное предположение, в UI обязательный бейдж «демонстрационная оценка».

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production-сборка в dist/
npm test         # 53 смоук-теста: скоринг, реактивность, roadmap, целостность датасета
```

Сборка настроена как single-file (`vite-plugin-singlefile`): весь бандл инлайнится в один `dist/index.html` — можно открыть даже с диска, роутер HashRouter работает на любом статическом хостинге.

## Техническая справка

- **AI/API не используются.** Логика рекомендаций — детерминированный rule-based движок (`src/engine/scoring.js`): прозрачно, мгновенно, стабильно на демо, каждая причина — отдельный объект данных.
- **Секретов в коде нет** — сервис полностью клиентский, ключи не требуются.
- **Персональные данные не покидают браузер** — всё в localStorage, сброс кнопкой «Сбросить» в анкете.
- Демо-профиль Алихана (17 лет, 11 класс, GPA 4.85, IELTS 6.0, цель Computer Engineering в Турции, план Б — Казахстан) загружается кнопкой «Демо-профиль Алихана» в анкете.
- Персонаж вымышлен; реальные сущности (METU, ITU, TR-YÖS, Türkiye Bursları, Дарын, ЕНТ) описаны с пометками источников или демо-флагами.

## Готовые компоненты

- `Choice` / `Chip` — интерактивные селекторы анкеты
- `VerifiedBadge` / `DemoBadge` — обязательные флаги источников из спеки
- `ProgressRing` — кольцо прогресса выполнения плана
- `buildRoadmap` / `getNextAction` — генерация плана и next action
- `getFearAccent` / `buildDocsChecklist` — режимы «главного страха» (data/fearModes.js)
